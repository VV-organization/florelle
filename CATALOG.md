# Каталог Florelle

Данные Flower Point: 1000 предложений / 511 уникальных товаров / 483 уникальные фотографии. Оригинальные локальные фотографии остаются в `public/catalog`, прозрачные варианты — в `public/catalog/cutouts`. Поле `source_image` связывает обработанный файл с оригиналом. Исторические изображения заказов разрешаются через `flowerImage`.

## Обработка

По согласованному с пользователем способу использована локальная сегментация, без генеративной перерисовки: rembg 2.0.61, isnet-general-use, BiRefNet General Lite для сложных светлых объектов. RGB оригинальных фотографий сохраняется; меняется альфа-канал, затем обрезаются пустые поля и добавляется небольшой прозрачный отступ. Be Sweet и фото букета с рукой уточнены по контуру; у упаковки орхидей сохраняется сам товар, убран внешний фон. Некоторые исходные снимки содержат вазы, упаковку, коллажи или обрезанные краем кадра цветы — они не дорисовываются.

`cutout-catalog.py` выполняет основную обработку; `refine-cutouts.py` и `refine-more-cutouts.py` обрабатывают отмеченные при визуальном контроле случаи. Нужны Python, Pillow и `rembg[cpu]==2.0.61`; модели загружаются в каталог `U2NET_HOME`. Для обычного запуска сайта и деплоя эти зависимости не нужны — WebP уже сохранены.

Карточки каталога, главная, просмотр товара, корзина, история заказов и категории используют один светлый серо-розовый цвет `--flower-backdrop: #efebea`. Убрано multiply-смешивание, которое изменяло цвет лепестков.

## Данные и тексты

`refresh-catalog.py` читает только публичный API товаров и курсов, обновляет существующие предложения и сохраняет исходные описания. Не обращается к чужим аккаунтам и заказам. Изменение исходной фотографии требует ручной проверки: скрипт останавливается, не заменяя готовый вырезанный файл.

`rewrite-catalog-copy.py` собирает новые краткие описания из подтверждённых характеристик источника; для ключевых сортов написаны отдельные тексты. Исходники в `catalog-source-copy.json` позволяют проверять факты. Скрипт не меняет размеры стеблей, количество в коробке, страны или цены. Несоответствия фотографий и названий у источника (например, MAYRAS WHITE использует фото красной розы) не исправлялись выдуманными изображениями.

Цены и курсы — проверенный снимок 29.09.2026, а не автоматическая синхронизация в реальном времени.
