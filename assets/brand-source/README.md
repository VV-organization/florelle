# FLORELLE identity

Original eight-petal rosette with bilingual circular lettering. ERA Residence supplied the art direction: circular floral seal, elongated serif wordmark, milk-on-plum presentation. The flower geometry and FLORELLE lockup are our own assets.

Wordmark outlines: Oranienbaum Regular (Oleg Pospelov / Jovanny Lemonad), sourced from https://www.fonts.uprock.ru/fonts/oranienbaum under SIL OFL 1.1; lettering condensed horizontally, tracked and converted to paths for this logo. Circular lettering: Google Sans, SIL OFL, using the archived source font. License texts included. SVG artwork contains no font dependency or external resources.

- `florelle-wordmark-{cream,plum}.svg`: standalone wordmark.
- `florelle-seal-{ru,en}-{cream,plum}.svg`: circular seal.
- `florelle-flower.svg`: simplified mark, also adapted for favicon.
- Source generator: `scripts/build-brand.py`.

Cream: #f5f1eb. Plum: #2c1928. Website lockup is composed in BrandLogo. Keep each SVG's aspect ratio and avoid shadows, gradients or synthetic strokes. Small navigation uses the wordmark with the same decorative seal; larger gateway/footer instances show the circular inscription more clearly.

2026-09-29 revision: enlarged circular lettering (13/10 SVG units), seal-only logo on gateway/header/footer; removed adjacent wordmark and caption from the live component. Standalone wordmark files remain available as source assets.
