# Bloom-send — типографика

После VV-173 интерфейс использует два локальных семейства:

- **Prata Regular** — заголовки страниц, разделов и товаров.
- **Manrope Variable 200–800** — текст, навигация, цены, кнопки, формы и имя клиента рядом с приветствием.

Рукописный Passions Conflict RUS отключён, включая preload. У заголовков нет рукописных или наклонённых акцентов. Длинные новые заголовки переносятся через `MotionText singleLine={false}`, сохраняя обычную анимацию появления. Исходные файлы и лицензия прежнего шрифта остаются в репозитории, но интерфейс их не загружает.

## Логотип

Цветочная розетка с круговой надписью «BLOOM-SEND · ПОСТАВКИ ЦВЕТОВ» / «BLOOM-SEND · FLOWER SUPPLY». SVG-контуры генерируются командой `python3 scripts/build-brand.py` из папки frontend; необходим пакет Python `fonttools`. Исходные OFL-шрифты лежат в `assets/brand-source`.

Надпись вращается, цветочный центр неподвижен. Reduced motion останавливает вращение. Логотип не зависит от загрузки веб-шрифтов.
