# Florelle — цветы вместо слов

Самостоятельная витрина Florelle на Next.js 16 / React 19. Локальный адрес: http://127.0.0.1:5194.

## Запуск

Node.js 24, npm и собственный backend Florelle (соседняя папка `../backend`).

```sh
npm ci
npm run dev
```

`BACKEND_URL` задаёт адрес backend, по умолчанию `http://127.0.0.1:5195`. Next проксирует `/api/v1/*` и `/media/*` на этот адрес. Браузер обращается только к своему origin. Для production сборки `BACKEND_URL` нужно установить во время сборки и запуска.

```sh
npm run typecheck
npm test
npm run build
```

`npm run build` создаёт серверную сборку standalone. GitHub Pages и статический экспорт больше не используются. Подготовка и запуск контейнера описаны в [DEPLOY.md](DEPLOY.md). Для HTTP-проверки каталога и фотографий на запущенном приложении: `TEST_BASE_URL=http://127.0.0.1:5194 npm test`.

## Данные и состояние

Каталог, коллекции, тарифы, валютные курсы, остатки и метаданные фотографий приходят из API собственного backend. Поиск, множественные фильтры, сортировка и пагинация по 24 предложения выполняются на сервере. Фотографии и responsive-варианты хранятся на постоянном диске backend и доступны по `/media`.

TanStack Query управляет загрузкой и обновлением серверных данных. Access token находится только в памяти, refresh token — в HttpOnly cookie. После обновления страницы сессия восстанавливается через `/auth/refresh` и `/auth/me`. Регистрация подтверждается кодом из письма; профиль сохраняет имя, телефон и компанию.

Корзина принадлежит аккаунту и его формату покупки; гостевой выбор ведёт ко входу с возвратом на исходную страницу. В localStorage сохраняются только язык, валюта и формат просмотра. Заказы и корзина в браузере не сохраняются.

Оформление использует серверный расчёт `/checkout/quote`, передаёт получателя, адрес, дату, интервал и способ доставки. `/orders` вызывается с ключом идемпотентности. Переход к оплате выполняется только по настоящему URL, возвращённому backend; ожидающий заказ опрашивается по его ID. Настройки SMTP и платёжного провайдера принадлежат backend.

## Визуальная основа

Сохранены палитра, DOM классы, композиция, адаптивная сетка, WebGL-ботаника, раскрытие обложки, арочный переход между входом и витриной, горизонтальная галерея и анимация текста. В CSS заменены только пути к четырём фоновым фотографиям на значения из API.

Prata, Manrope и Passions Conflict RUS остаются локальными WOFF2; лицензии OFL включены. Подробности: [TYPOGRAPHY.md](TYPOGRAPHY.md). Исходный каталог и фотографии сохранены вне runtime frontend; импорт описан в [CATALOG.md](CATALOG.md).
