# Каталог и фотографии

Runtime frontend получает каталог, остатки, цены, коллекции, тарифы, курсы и фотографии из собственного API Florelle. Локальные коммерческие JSON и копии каталожных фотографий из frontend удалены после проверки импорта.

Архив исходной витрины: `../.artifacts/reference`. Команда импорта, схема PostgreSQL, постоянный media-диск, сверка контрольных сумм оригиналов/вариантов и проверка повторного импорта находятся в `../backend`. Архив сохраняет исходные 511 товаров, 1000 предложений, 31 категорию, коллекции, тарифы 37 городов и фото с метаданными кадрирования.

`/api/v1/storefront/content` возвращает редакционные подборки и соответствие прежних путей собственным `/media` URL. `/api/v1/products` выполняет поиск и фильтрацию с пагинацией; `/api/v1/products/:slug` возвращает товар и предложения плантаций. Поле `photo.variants` задаёт `srcSet`, а `photo.framing` сохраняет положение стебля в карточке. Декоративные сцены используют те же фотографии и размеры через media API.

Проверка витрины после запуска backend и frontend:

```sh
TEST_BASE_URL=http://127.0.0.1:5194 npm test
```

Импорт каталога и миграции БД не запускаются из frontend и не обращаются к исходному внешнему магазину.
