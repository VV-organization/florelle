# Сверка Florelle с Flower Point

29 сентября 2026. **Полного соответствия ТЗ пока нет.** Каталог и тарифы перенесены, но полноценная покупка с оплатой и обработкой заказа ещё не реализована.

## Метод проверки

Просмотрены публичные страницы источника в браузере, HTML и клиентский JavaScript. Прочитаны публичные API товаров, коллекций и валют: по 1000 предложений в каждом сегменте. Аккаунты на Flower Point не создавались; его API регистрации, корзины, заказов и оплаты не вызывались.

Защищённые сценарии кабинета, оформления и оплаты изучены по публичному клиентскому коду. Их реальный серверный результат не проверен. Наличие вызова в коде не доказывает успешный платёж или доставку письма.

## Порядок завершения ТЗ

**Без внешних ключей:** недостающие поля и согласия, состояния подтверждения email, отдельное оформление, минимальный заказ, автоматический вес, серверная корзина, страницы и статусы заказов, фильтры/сортировка/маршруты и оставшаяся информация. Отсутствие платёжных ключей не блокирует эти работы.

**С собственными данными и подключениями:** юрлицо и поддержка, почтовый отправитель для кодов, платёжный провайдер с проверяемыми webhook, подтверждённый источник остатков/цен и процесс исполнения заказов. Комиссию следует реализовать по подтверждённому правилу, а не произвольному проценту.

**Критерий готовности:** оба типа покупателей проходят регистрацию → подтверждение → товар и продавец → корзину → доставку → оформление → тестовый платёж провайдера → заказ с корректным статусом. Проверяются отмена/ошибка платежа, повторный callback, повторный вход и перезагрузка. Только после этого можно утверждать функциональное соответствие.

## Проверки

- Production-сборка завершилась успешно, включая TypeScript.
- Все 5 автоматических тестов прошли на изолированном production-сервере: данные, коллекции, файлы, аккаунты/сессии/черновики, production-шрифты.
- В браузере подтверждены 20 предложений бестселлеров, 15 летней коллекции, оптовые остатки и AMS.
- Проверка нескольких фильтров и сценария «другой продавец → добавление → уведомление → корзина» прервана из-за недоступности браузерной сессии. Не считать пройденной; нужна и повторная мобильная проверка.
- Реальная отправка кода, оплата и исполнение заказа не проверялись и не заявляются работающими.
