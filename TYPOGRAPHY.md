# Florelle — утверждённая типографика

Выбрано пользователем 29.09.2026:

- **Prata Regular** — заголовки страниц, разделов и товаров. [Uprock](https://www.fonts.uprock.ru/fonts/prata).
- **Manrope Variable 200–800** — обычный текст, навигация, цены, кнопки, формы. [Uprock](https://www.fonts.uprock.ru/fonts/manrope).
- **Passions Conflict RUS Regular** — короткие рукописные приписки. [Uprock](https://www.fonts.uprock.ru/fonts/passions-conflict-rus).

Все три шрифта обслуживаются локально из `public/fonts` в WOFF2. OFL 1.1 приложены. В файлах сохранены исходные имена гарнитур. Manrope содержит реальные веса для интерфейса; у Prata и Passions используется только Regular, без искусственного жирного начертания. Проверены русские буквы, Ё/ё, латиница; валюты и цифры отображает Manrope.

## Оптический баланс

Passions имеет невысокие строчные. Размеры приписок подбираются по реальным словам, а не равняются кеглю Prata. На развилке «бизнеса» / «себя» увеличены до 2.35em по замечанию пользователя. Рукописные слова не используются для цен, кнопок и длинных абзацев.

## Логотип

Отдельный векторный знак: оригинальная цветочная розетка и увеличенная круговая надпись. Боковая надпись убрана. Надпись вращается с базовой скоростью 30°/с и реагирует на прокрутку; центр неподвижен. Reduced motion останавливает вращение. SVG не зависит от загрузки шрифтов. Исходные OFL-шрифты для воспроизведения вектора сохранены в `assets/brand-source`, вне публичной папки.

## Материалы подбора

Экспериментальные страницы и прежние шрифты перенесены в локальный `output/design-archive` (исключён из Git и Docker). В production их нет; маршруты `/type-study/*` возвращают 404. В `public/fonts` находятся только три утверждённых семейства и их лицензии.
