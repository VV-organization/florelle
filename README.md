# Florelle — цветы вместо слов

Локальный сайт: http://127.0.0.1:5194

## Запуск

Node.js 24 (используется встроенный SQLite), npm.

```sh
npm install
npm run dev
```

Проверки: `npm run typecheck`, `npm run build`. Для `npm test` сначала запустите приложение; адрес меняется через `TEST_BASE_URL`.

## Реализовано

- Отдельный вход /: выбор формата покупки, затем розничная главная /b2c или оптовая главная /b2b. До выбора витрина не отображается. Адаптивная главная с ботанической обложкой: растения плавно изгибаются от ветра (WebGL), цветы раскрываются непрозрачной кистью с мягким краем и коротким следом за указателем. Кнопка полностью раскрывает композицию и возвращает зелень; учитывается reduced motion, при недоступном WebGL работает CSS-версия.
- 1000 предложений, 511 сортов/товаров с локальными оригинальными фотографиями, 31 категория, коллекции, поиск, цветовые и ценовые фильтры, сортировка, постраничный вывод.
- Розничный и оптовый режимы: стебли / коробки, разные цены, предложения плантаций, отдельные страницы товаров и быстрый просмотр.
- RUB / KZT / TRY, русский / английский интерфейс.
- Доставка: Россия, Казахстан, Турция, 37 городов, тарифы по весу и минимальному заказу, розничные способы доставки.
- Корзина с сохранением в браузере, изменение количества, удаление, защита от дублей, доступное уведомление и переход в корзину из всех карточек.
- Собственная регистрация, вход, профиль, сессии HttpOnly, сохранение черновиков заказов и история в кабинете. Пароли хешируются scrypt; сумма заказа рассчитывается на сервере.

## Данные и подключения

Каталог, фотографии и тарифы — снимок публичного Flower Point на 28.09.2026. Данные находятся в `src/data`; фотографии в `public/catalog`. Курсы также фиксированы снимком. Скрипты в `scripts` фиксируют этапы импорта; это не фоновая синхронизация.

Приложение не обращается к аккаунтам, корзине и заказам оригинального сервиса. Пользователи и черновики хранятся только в локальной базе `data/store.sqlite` (исключена из Git).

Для коммерческого запуска нужны собственные реквизиты продавца, договорённость с поставщиком, актуальные остатки и цены, платёжный провайдер, подтверждение доставки и почтовый сервис. Сейчас сохранение создаёт черновик: товар не резервируется, деньги не списываются. Восстановление пароля через почту пока не подключено. Юридические страницы описывают текущую механику и требуют реквизитов оператора перед запуском.

Для сервера с HTTPS задать `APP_ORIGIN=https://ваш-домен` и обеспечить постоянный диск для SQLite. Текущий сервер рассчитан на один экземпляр; для масштабирования нужны общая БД и общий лимитер запросов. Подготовлены Docker, Render Blueprint и GitHub Actions. Инструкция: [DEPLOY.md](DEPLOY.md). Публичного деплоя пока нет.

## Основа дизайна

- [Flower Point](https://flower-point.com): ассортимент, фотографии, функциональные сценарии, доставка и валюты.
- [Urban Living](https://realevate.agency/urbanliving): сливово-бордовая палитра, крупная гротескная типографика.
- [LxL Creative](https://www.lxlcreative.co.uk): сочетание рукописных акцентов с гротеском, крупный типографический финал.
- [ERA](https://www.era-residence.com): свободная композиция, фотография и деликатные подписи.
- [Sobha Privy](https://sobha-privy-collection.com): фотографические переходы и крупные композиции.
- [Squarespace Foundations / Resn](https://brand.squarespace.com): ботанический образ с пользовательского скриншота; для этого сайта созданы два согласованных изображения и реализовано раскрытие через маску.
- Технические ориентиры Frags: Next.js / React / TypeScript, сохранение корзины, быстрый просмотр, кабинет и история. Код специфичных для Frags механик не переносился.

Типографика проверена по CSS референсов: Google Sans (Urban Living), Owners Wide (LxL); русские рукописные акценты — Comforter Brush из Uprock, выбранный по сходству со Scribo из LxL. Источники, поддержка кириллицы и условия подключения описаны в `TYPOGRAPHY.md`.
