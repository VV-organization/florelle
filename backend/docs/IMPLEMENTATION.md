Independent shop. Preserve Florelle visual UI, animations and existing form fields. Replace SQLite and local commerce with Fastify/PostgreSQL/Redis based on Flower Point 47d112e. Source frontend baseline 130ef91 is archived at ../../.artifacts/reference. Preserve static catalog (511 products, 1000 listings, 31 categories), IDs, collections, exact RUB retail/wholesale/AMS values, inventory in stems, delivery tables and all photographs. Backend public API /api/v1. Auth access token in memory and refresh cookie, email verification; GET/PATCH /auth/me. Cart is authenticated and segment-bound, 24h expiration. Catalog supports search/multiple filters/24-per-page. Checkout quote uses authoritative server cart and DB delivery tariff, B2C >=1000 RUB including commission excluding shipping; commission default 12%. B2B weight ceil(stems*.092). B2C preserve Florelle tariffs and requested date/time/mode. Checkout and provider intents durable/idempotent; externalId before QRC, never release inventory on uncertain provider outcome, verified amount/currency/identity webhooks only. Immutable order snapshots and display money. Arcopay SBP RUB, SMTP, VV Admin separate credentials. No balance UI.

Frontend keeps Next16/React19 and current CSS/DOM/visual assets; ordinary route pages with shared shell, server data via query client. Existing profile editable; preserve full name, phone/company, requested delivery date/time/mode. No SQLite/local carts/static commercial JSON runtime. Own media metadata returned by API. Typecheck, build, unit/API/DB tests, desktop/mobile screenshots. No push/deploy or real external messages/payments without explicit external credentials/test authorization.
